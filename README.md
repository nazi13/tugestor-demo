# دموی استخراج فاکتور

یک پوشه از عکس یا PDF فاکتورها را می‌خواند، اطلاعات را با Claude بیرون می‌کشد، چند بررسی خودکار انجام می‌دهد و یک فایل Excel می‌سازد. ردیف‌هایی که نیاز به بررسی انسان دارند زرد می‌شوند و دلیلشان در ستون «Revisar» نوشته شده است.

## راه‌اندازی

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...   # کلید API از console.anthropic.com
```

## اجرا

```bash
python extract.py ./facturas -o facturas.xlsx     # با API واقعی
python extract.py ./facturas --mock                # داده‌ی نمونه، بدون API (برای تست)
python test_validators.py                          # تست بررسی‌ها
```

فرمت‌های پشتیبانی‌شده: jpg، png، webp و pdf. عکس‌های خیلی بزرگ موبایل خودکار کوچک می‌شوند.

## بررسی‌های خودکار

- معتبر بودن NIF / CIF / NIE (با checksum)، برای شمارهٔ مالیاتی فروشنده و خریدار
- درست بودن حساب: پایه × نرخ = IVA، و پایه + IVA − retención = جمع کل
- نرخ‌های عادی IVA (۰، ۴، ۱۰، ۲۱)؛ نرخ غیرعادی علامت می‌خورد
- تاریخ ناخوانا یا در آینده، نبودن شمارهٔ فاکتور
- فاکتور تکراری (همان NIF و همان شماره) در یک دسته
- اعلام «اطمینان کم» توسط مدل

## قدم‌های بعدی (بعد از صحبت با اولین gestoría)

1. خروجی را با فرمت واردسازی نرم‌افزار همان دفتر (A3، Sage، Contasol و غیره) هماهنگ کن.
2. ورودی از واتساپ یا ایمیل (فعلاً فقط پوشه).
3. یک صفحهٔ وب ساده برای بازبینی ردیف‌های زرد.

## حریم خصوصی

فاکتورها اطلاعات شخصی دارند. برای تست فقط از فاکتورهای خودت یا مدارک ناشناس‌شده استفاده کن. برای مشتری واقعی، قرارداد پردازش داده (RGPD) لازم است.
